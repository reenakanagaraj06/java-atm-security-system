# Smart ATM Security System

A beginner Java console project that simulates ATM security
and withdrawal eligibility.

## Concepts Used

- Java Scanner
- Boolean data types
- Logical AND (&&)
- Logical NOT (!)
- Relational operators
- Arithmetic operations
- Formatted output

## Features

- Checks card validity
- Checks PIN correctness
- Checks account status
- Checks whether the user is blocked
- Checks withdrawal eligibility
- Calculates remaining balance
